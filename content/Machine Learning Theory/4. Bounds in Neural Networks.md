#### Rademacher Complexity
- Measures how well the hypothesis class can fit random noise.
- If the model class can fit anything, including pure noise, it has high Rademacher complexity and won't generalize well.

*The spectral/path norm bounds are just upper bounds on Rademacher complexity, which is itself an upper bound on generalization error. Both of these bounds attempt to answer the same question: how well will our trained network generalize?*

The tighter we can bound the Rademacher complexity $R_n$, the more we know about generalization.
#### Spectral norm bound
- Spectral norm measures the maximum stretching of each individual layer
- It's a per-layer measurement. For a two-layer network, it's computed twice and then multiplied together in the bound

Example 2.1.2
Let $\mathcal{H} = \{f_\Phi \mid \|w\| \leq B', \|U\|_2 \leq B\}$. Then the Rademacher complexity of $\mathcal{H}$ is bounded by$$
R_n(\mathcal{H}) \leq 2BB'\sqrt{\frac{m}{n}}
$$
- Here, $\|U\|_2$ is the largest singular value (spectral norm) of the first layer weight matrix.
- $\|U\|_2$ controls how much the first layer can stretch an input vector
- A large spectral norm means the layer amplifies the inputs a lot, making the network more sensitive to small changes, which is bad for generalization
- The $\sqrt m$ factor is the problem: the bound gets worse as more neurons are added, even if empirically wider networks generalize fine.

#### Path norm bound
- Path norm measures the end-to-end contribution of each neuron through the whole network.
- Path norm solves the issue with the spectral norm bound by no dependence o $\sqrt m$ at all.
- The path norm is $P(w, U) = \sum^m_{j=1} . \|u_j\|_2$, where $u_j$ are rows in $U$. Let $\mathcal{H} = \{f_\Phi \mid P(w, U) \leq B\}$. Then, the Rademacher complexity of $\mathcal{H}$ is bounded as follows
$$
R_n(\mathcal{H}) \leq \frac{2B}{\sqrt{n}}
$$
where $B = P(w,U)$. 
- The intuition is that neurons with tiny $|w_j|$ contribute almost nothing to the output (the path norm discounts them). So, even in a wide network, if most neurons are small, the effective complexity stays low.
-
Spectral norm is like measuring the loudest instrument in orchestra, while path norm is like measuring the total weighted contribution of every instrument to the actual sound.
